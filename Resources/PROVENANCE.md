- Home.html: original HTML/CSS/SVG start page written for this prototype.
- PiPDemo.html: original local playback fixture.
- PiPDemo.mp4: original deterministic FFmpeg `testsrc2` video with no audio, generated by scripts/generate-demo.sh. It contains no Arc media.
