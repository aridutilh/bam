# Resource provenance

- ArkIcon.png: newly generated crayon-style reinterpretation of the Arc logo, created with the built-in image-generation tool using Arc’s installed app icon as a visual reference. The reference itself is not redistributed. See [branding notes](../docs/branding.md) for the full prompt. ArkIcon.icns is generated from this PNG with macOS sips/iconutil.

- Home.html: original HTML/CSS/SVG start page written for this prototype.
- PiPDemo.html: original local playback fixture.
- PiPDemo.mp4: original deterministic FFmpeg `testsrc2` video with no audio, generated by scripts/generate-demo.sh. It contains no Arc media.
- SmokeA.html and SmokeB.html: original minimal navigation fixtures.
- Sidebar artwork is drawn by Ark or uses SF Symbols provided by macOS at runtime. No Apple symbol font is redistributed.

The public repository and release contain no extracted Arc artwork, animation JSON, pre-rendered animation frames, or onboarding media. Ark is independent and is not affiliated with The Browser Company.
