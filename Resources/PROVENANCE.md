# Resource provenance

- BamIcon.png: original red sale-sticker burst on a light matte pink rounded square, with paper texture and a peeled corner. Created and refined with the built-in image-generation tool on October 23, 2026; this approved master is the light-pink iteration. It contains no extracted Arc artwork. See [branding notes](../docs/branding.md) for the final editing prompt. BamIcon.icns is mechanically generated from this PNG with macOS sips/iconutil.
- Home.html: original HTML/CSS/SVG start page written for this prototype.
- PiPDemo.html: original local playback fixture.
- PiPDemo.mp4: original deterministic FFmpeg `testsrc2` video with no audio, generated by scripts/generate-demo.sh. It contains no Arc media.
- SmokeA.html and SmokeB.html: original minimal navigation fixtures. Their legacy Orbit titles support existing test assertions.
- Sidebar artwork is drawn by Bam or uses SF Symbols provided by macOS at runtime. No Apple symbol font is redistributed.

The public repository and release contain no extracted Arc artwork, animation JSON, pre-rendered animation frames, or onboarding media. Bam is independent and is not affiliated with The Browser Company.
